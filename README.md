# Au-Some Notarific Services LLC — Version 1

Live website: https://mhh.gemzonline.com/

Standalone responsive HTML/CSS/JavaScript website. Open index.html or serve this directory locally. No dependencies or build step.

Services: Florida Notary Services, Jamaican Passport Renewals, and Jamaican Driver’s License Renewals. By appointment; mobile services are not offered.

Contact Melicia opens a form and prepares an email for the visitor to review and send. No server-side delivery or personal-data storage is configured.

Assets include an AI-assisted extraction of Melicia from the supplied reference flyer and generated decorative coastal and service imagery. Labels, cards, controls, and legal disclaimer use real HTML/CSS.

Version 1 matches the published website after removal of mobile-service wording. Original layout checks covered widths 1440, 1024, 768, 390, and 320 pixels. The published Version 1 homepage was verified against the saved file.

Deploy only index.html, styles.css, app.js, and assets/ to public_html. Hosting credentials are excluded.
